# Lab 1: Ethics, Fairness, and Bias in Machine Learning

## Overview

In this lab, I explored how machine learning models can inherit bias from data and how to evaluate fairness across different demographic groups.

## What I Did

- Loaded and cleaned the Adult Income dataset
- Built a Logistic Regression model
- Evaluated model accuracy
- Performed fairness analysis by gender
- Calculated subgroup accuracy
- Analyzed False Positive Rate (FPR) and False Negative Rate (FNR)

## What I Learned

- Models can appear accurate overall but still be unfair
- Subgroup analysis is critical for ethical ML
- Different types of errors affect groups differently
- Removing sensitive features does not eliminate bias

## Challenges

- Understanding fairness metrics
- Interpreting confusion matrix results
- Connecting technical results to real-world ethical impact

## Key Insight

Fairness in machine learning requires more than accuracy—it requires careful evaluation of how models impact different groups.
