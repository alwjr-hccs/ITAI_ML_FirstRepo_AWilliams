# Employee Attrition Prediction

This project predicts whether an employee will leave a company using HR and workplace data.

## Included
- Full training pipeline
- Real run outputs generated from the uploaded IBM HR Analytics dataset
- Model comparison table
- Classification reports
- Confusion matrices
- ROC curve
- Feature importance plot
- Saved best model

## Run
```bash
pip install -r requirements.txt
python src/train.py
```
